## 1. Executive Summary

**NexaStack** is a multi-tenant, white-label SaaS platform designed to empower franchise partners, digital agencies, and individual resellers to sell premium digital products to local businesses — all without writing a single line of code.

The platform bundles **7 high-demand digital products** under one roof, each designed to be created in **under 15 minutes** by a non-technical user. Franchise owners onboard local clients, earn recurring commissions, and build a scalable digital business with zero upfront development cost.

### Key Highlights

| Metric | Target |
|--------|--------|
| Product Setup Time | 10–15 Minutes |
| Technical Knowledge Required | Zero |
| Revenue Sharing for Franchise | 15–25% per sale |
| Referral Bonus | ₹100 per qualified referral |
| Target Markets | India (Tier 1/2/3 cities), SE Asia, Middle East |
| Supported Languages | English, Hindi, Tamil, Telugu, Malayalam (expandable) |
| Deployment Model | Cloud SaaS (Multi-tenant) |

## 4. User Roles & Access Levels

### 4.1 Super Admin
The platform owner. Full control over everything.

**Capabilities:**
- Create, activate, deactivate franchise accounts
- Set global product pricing and commission rates
- Override any franchise-level settings
- Access consolidated revenue reports across all franchises
- Manage all customer accounts globally
- Configure AI model integrations (OpenAI, Gemini, etc.)
- Manage template library (add/remove/approve templates)
- Set up payment gateway keys (Razorpay, Stripe, PayU)
- Run platform-wide announcements and alerts
- Access fraud detection and audit logs
- Configure referral rules and bonus amounts
- Manage subscription plans (Basic, Pro, Enterprise)
- View real-time platform analytics dashboard
- Control white-label domain mapping for each franchise
- Manage API keys and third-party integrations
- Send mass emails/SMS to all users

- Set custom pricing for their customers (within allowed margin)
